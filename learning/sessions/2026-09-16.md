## Work
- Change `mate-in-one-curriculum`: reverse curriculum by start state (Florensa
  et al. 2017; Salimans & Chen 2018). Lichess puzzle DB (CC0) -> 20k train /
  2k held-out mate-in-one positions (`scripts/prepare_puzzles.py`); env reset
  from FEN via `new_initial_state` + `set_state`; held-out metrics (top-1,
  mating-move probability) every `eval_interval` updates.
- Run 1 (mix by reset, 0.5): flat. Diagnosed: missed mates became long games,
  ~200 attempts total. Revised (owner approved): one-move puzzle episodes on
  `round(puzzle_fraction * num_envs)` fixed boards, miss = terminal with
  `puzzle_miss_reward` (default 0), metrics split by source.
- Run 2 (seed 0): held-out top-1 0.074 -> 0.352, no train/held-out gap; in-game
  mate rate 4.7% -> 18%, decisive 22% -> 40%, games half as long. Black won
  24 of 30 decisive eval games; cause localised to white's exposure, not
  finishing. Seed-1 run launched to separate "weaker network" from "colour bug".
- Profiling: forward 0.65 s + backward 1.02 s per update, environment 0.07 s;
  sync vs async 95.8 s vs 91.2 s per 100 updates. A Rust environment would not
  help; the network is the cost.

## Lessons (records 0006-0008)
6. Start-state curricula need failed attempts to end quickly; otherwise attempts,
   not updates, are the bottleneck. Split metrics by episode source.
7. A non-zero start potential shifts all returns by -scale*Phi; the advantage and
   the policy are untouched (Corollary 2 again).
8. A colour asymmetry was exposure (walking into mates), not finishing; sample
   size was tested and rejected with a second seed.

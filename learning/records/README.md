# Learning records

One short file per insight, numbered `0001-slug.md`, `0002-slug.md`, ...

Record only:
1. demonstrated understanding of something non-trivial,
2. disclosed prior knowledge (and its depth),
3. a corrected misconception,
4. a mission shift.

Not a session diary. Format: a title and 1-3 sentences on what was learned and why
it matters for what comes next. Mark an outdated record `Status: superseded by 000N`
instead of deleting it.

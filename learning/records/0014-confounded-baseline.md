# The base was polluted (2026-09-17)

While the exploration arms were being read, the owner asked: "isn't the fin3
start already polluted with previous evaluation using material also?" It was:
FIN3 carried 600 shaped updates under 300 clean ones, so every arm that day was
also fighting shaped habits. The clean arm the owner asked for (SL -> outcome-only,
600 updates) then showed shaping had never helped from the prior (0.647 / 0.565
vs 0.570 / 0.510 at 600 updates) and became the new base. Why it matters: a
control arm is only a control if it shares the whole lineage; when the base
itself embodies the variable under test, rebuild the base before reading the arm.
